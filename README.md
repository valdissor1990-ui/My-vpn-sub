# My VPN Sub

Автоматический агрегатор рабочих бесплатных VPN/прокси-конфигов  
(VLESS · VMess · Trojan · Shadowsocks).

Скрипт каждые 4 часа:
1. Скачивает публичные подписки из нескольких источников
2. Проверяет серверы через TCP
3. Оставляет только живые и быстрые
4. Убирает дубликаты
5. Сохраняет результат в `sub.txt` (максимум 50 самых быстрых)

## Как это работает

| Этап | Описание |
|------|----------|
| Источники | 8 публичных GitHub-репозиториев с base64/plain подписками |
| Парсинг | Извлекает `vless://`, `vmess://`, `trojan://`, `ss://` |
| Проверка | TCP-подключение к host:port (таймаут 3 сек) |
| Фильтр | Пинг < 1500 мс |
| Дедупликация | По host:port — остаётся самый быстрый |
| Лимит | **Максимум 50 серверов** (только самые быстрые) |
| Сортировка | От самого быстрого к медленному |

---

## Настройки (`config.py`)

```python
CONNECT_TIMEOUT = 3   # секунд на TCP-проверку
MAX_PING = 1500       # максимальный пинг (мс)
MAX_WORKERS = 30      # параллельных потоков
MAX_SERVERS = 50      # максимум серверов в sub.txt
PROTOCOLS = ["vless", "vmess", "trojan", "ss"]
```

Можно менять эти значения под себя.

## Ручной запуск

```bash
git clone https://github.com/valdissor1990-ui/My-vpn-sub.git
cd My-vpn-sub
pip install -r requirements.txt
python collector.py
```

После выполнения появится/обновится файл `sub.txt`.

## Автообновление

GitHub Actions запускается:
- по расписанию каждые **4 часа**
- вручную (Actions → Update Subscription → Run workflow)
- при изменении кода коллектора

## Важные замечания

- Это **бесплатные публичные** конфиги. Качество и стабильность не гарантируются.
- Использовать только для легальных целей и на свой страх и риск.
- TCP-проверка показывает, что порт открыт, но не гарантирует, что протокол полностью рабочий.
