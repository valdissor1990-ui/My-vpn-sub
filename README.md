# My VPN Sub

Автоматический агрегатор + мониторинг рабочих бесплатных VPN/прокси-конфигов  
(VLESS · VMess · Trojan · Shadowsocks).

**Что делает каждые 2 часа:**
1. Скачивает конфиги из 16+ открытых бесплатных источников
2. Проверяет каждый сервер через TCP (мониторинг доступности)
3. Оставляет только живые и быстрые (пинг < 1200 мс)
4. Убирает дубликаты
5. Сохраняет **топ-50** самых быстрых в `sub.txt`

## Как это работает

| Этап | Описание |
|------|----------|
| Источники | 16+ публичных GitHub-репозиториев с бесплатными конфигами |
| Парсинг | `vless://`, `vmess://`, `trojan://`, `ss://` |
| Мониторинг | TCP-проверка каждого сервера |
| Фильтр | Пинг < 1200 мс |
| Дедупликация | По host:port — остаётся самый быстрый |
| Лимит | **Топ-50** самых быстрых серверов |
| Расписание | Автообновление **каждые 2 часа** |

---

## Настройки (`config.py`)

```python
CONNECT_TIMEOUT = 3   # секунд на TCP-проверку
MAX_PING = 1200       # максимальный пинг (мс)
MAX_WORKERS = 40      # параллельных потоков
MAX_SERVERS = 50      # максимум серверов в sub.txt
PROTOCOLS = ["vless", "vmess", "trojan", "ss"]
```

## Важные замечания

- Это **бесплатные публичные** конфиги. Стабильность не гарантируется.
- Использовать только для легальных целей.
- TCP-проверка показывает доступность порта, но не гарантирует 100% работоспособность протокола.
